# Basic Image Converter

A web application that allows you to convert images from one format to another on your web browser.

This tool runs **100% on your computer**. Your browser does all the hard work, it costs \$0 to host, works instantly, and keeps your files completely private (your images are never uploaded to any server).

---

##  How it Works

The project is split into three separate files:

1.  **HTML5 (`index.html`):** Creates the layout, buttons, and structure of the app.
2.  **CSS3 (`style.css`):** Handles the design.
3.  **JavaScript (`script.js`):** The "brain" of the app.

---

##  Project Structure

Make sure all three files are saved together in the exact same folder on your computer:

folder
├── index.html   # The structure and layout
├── style.css    # The colors, fonts, and designs
├── script.js    # The logic and image conversion code
└── README.md    # This documentation file


---

##  How to Run the Project

1.  Download these files to your computer.
2.  Put `index.html`, `style.css`, and `script.js` in the same folder.
3.  **Double-click** the `index.html` file.
4.  It will open in your default web browser
